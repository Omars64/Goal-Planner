# Contributing

1. Fork the repository and create a focused branch.
2. Run `npm ci` and create `backend/.venv` from `backend/requirements.txt`.
3. Keep API changes backward-compatible or update the frontend client and tests in the same pull request.
4. Run `./scripts/check-all.sh` before opening a pull request.
5. Explain user-visible changes and include tests for fixed regressions.

The visual theme is an original neon crime-game-inspired interface. Do not contribute copyrighted game artwork, logos, fonts, audio, or extracted assets.
